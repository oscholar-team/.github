### 从阅读发现，到交流协作

Oscholar 围绕论文阅读、研究想法和学术交流，构建持续协作的研究空间。我们希望让研究者更方便地发现知识、整理思路，并与他人一起推进研究。

| 探索知识 | 记录想法 | 连接研究者 |
| :--- | :--- | :--- |
| 发现与阅读论文，整理值得深入的问题。 | 在 Mini paper 中组织材料、记录变化、交流修改建议。 | 围绕研究内容展开讨论，让想法获得反馈。 |

### 一起改进 Oscholar

**使用产品** → [打开官网](https://www.oscholar.cn/home)，体验论文与 Mini paper 工作空间。  
**报告问题** → [提交 Bug](https://github.com/oscholar-team/.github/issues/new?template=bug-report.yml)，附上复现步骤和预期行为。  
**提出想法** → [提交需求](https://github.com/oscholar-team/.github/issues/new?template=feature-request.yml)，说明使用场景和希望解决的问题。

公开反馈请勿包含密码、验证码、访问令牌、未公开稿件或个人敏感信息。安全问题请使用相关仓库的私密漏洞报告渠道（若已启用），不要在公开 Issue 中披露细节。

### 我们如何协作

需求通过 Issue 明确范围与验收标准，较大的任务拆成子任务；代码通过 Pull Request 讨论和审查，结合测试与实际验收推进交付。AI Agent 辅助调查、实现和审查，团队对最终交付负责。
